การเชื่อมต่อ Google Sheet Backend

ตั้งค่าการซิงค์ข้อมูลกับ Google Sheets ผ่าน Google Apps Script Web App

เชื่อมต่อกับ Google Sheet ของคุณใน 3 ขั้นตอนง่ายๆ:
  1. เปิด Google Sheet ของท่าน (เช่น ลิงก์ที่เคยใช้เก็บข้อมูล)
  2. ไปที่เมนู ส่วนขยาย (Extensions) > Apps Script แล้วนำโค้ดในโฟลเดอร์ google-apps-script/Code.gs ไปวาง
  3. กด Deploy (การทำให้ใช้งานได้) > New deployment (รายการใหม่) > Web app (เว็บแอป) โดยตั้งค่าสิทธิ์เข้าถึงเป็น "Everyone (ทุกคน)" แล้วคัดลอก URL มาวางในช่องด้านล่าง
นำ Web App URL ที่ได้จากปุ่ม Deploy มาวางในช่องด้านบนแล้วกด "บันทึก & ทดสอบเชื่อมต่อ"
